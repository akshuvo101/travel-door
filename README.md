# Travel Door Demo

Bangladesh-focused travel website redesign concept built with Next.js, React, TypeScript and Tailwind CSS.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Notes

- This is a frontend demo/prototype.
- Content such as phone numbers, emails, statistics and testimonials are placeholders and should be replaced with verified Travel Door information.
- Images use remote Unsplash URLs for the demo.
- No database, authentication or admin dashboard is included yet.
- The next phase can add Supabase/PostgreSQL, an admin CMS, inquiry management, WhatsApp/email notifications and booking integrations.
